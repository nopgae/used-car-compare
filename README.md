# 공공기관 중고차 공매 시세

공공기관이 온비드(한국자산관리공사)에 내놓은 차량 공매의 낙찰 결과를 MySQL에 모아 **검색·비교·낙찰가 추정**을 하고, 지금 입찰 중인 차량의 **예상 낙찰가를 마감 전에 기록한 뒤 실제 낙찰가로 채점**하는 웹앱입니다.

- 데모: https://nopgae.github.io/used-car-compare/
- 데이터: 2018-01-02 ~ 2026-11-12 개찰 차량 공매 결과 78,085건, 그중 낙찰가가 있는 낙찰 46,346건 (2026-11-13 수집 기준, 이후 매일 증가)

> 공매 낙찰가는 관공서에서 쓰다 처분한 차(낙찰의 약 86%), 압류차 등의 거래가입니다. 일반 중고차 소매 시세와 다르고, 법원 경매는 포함하지 않습니다.

## 화면

| 경로 | 내용 |
|---|---|
| `/` | 낙찰 검색: 제조사·모델·차종·연식·주행거리·낙찰가 필터, 정렬 |
| `/compare` | 최대 3대 비교 + 같은 모델 계열·연식 ±1년 낙찰가 중앙값 대비 |
| `/estimate` | 모델 계열·연식·주행거리로 예상 낙찰가와 80% 범위, 비슷한 최근 사례 |
| `/live` | 진행 중 공매와 예상 낙찰가, 예측 성적표(마감 전 예측 vs 실제), 수집 이력 |
| `/trends` | 월별 낙찰 건수, 감정가 대비 낙찰가율, 전국 중고차 성능점검 건수 |

## 구조

```
맥(launchd, 매일 09:00·21:00, 자고 있었으면 깨어날 때)
  scripts/daily.sh
    ├─ ingest.ts        온비드 차량 입찰결과 → MySQL bids (최근 2개월 upsert)
    ├─ ingest-stats.ts  교통안전공단 성능점검 통계 → monthly_stats
    ├─ snapshot.ts      진행 중 차량 공매 → listings, 처음 본 물건에 예상 낙찰가 기록(이후 덮어쓰지 않음)
    ├─ export.ts        MySQL → public/data/*.json
    ├─ next build       정적 사이트(output: export)
    └─ deploy.sh        gh-pages 브랜치로 push → GitHub Pages
  모든 수집 작업은 ingest_runs에 호출 수·저장 건수·오류를 남긴다.
```

- 언어·프레임워크: TypeScript, Next.js 16(정적 export), React 19
- DB: MySQL 8.4 (Docker), 드라이버 `mysql2`, SQL 직접 작성
- 테스트: Vitest 28개 (`npm test`)
- 차트: 라이브러리 없이 SVG

## 낙찰가 추정과 검증

모델 계열마다 `log(낙찰가) = a + b·차령 + c·log(주행거리) + d·거래시점`을 최소제곱으로 맞춥니다(학습 30건 이상인 계열만, 외부 라이브러리 없음). 구급·소방·순찰차 같은 특수 개조 차량, 여러 대 묶음, 폐차 조건 매각은 학습과 예측에서 뺍니다.

**홀드아웃 검증** (`npm run evaluate` → `data/metrics.json`): 2026-05-12 ~ 2026-11-12 낙찰 1,656건을 떼어 두고 그 이전 데이터로만 학습

| 방법 | 오차 중앙값 | ±20% 안 | 평균 절대오차 |
|---|---|---|---|
| 이 추정 | 24.8% | 40.0% | 169만원 |
| 같은 모델 계열, 연식 ±2년 평균 | 44.0% | 26.1% | 252만원 |

80% 범위 안에 실제 낙찰가가 든 비율은 78.4%입니다. 차 상태·옵션·사고 이력은 데이터에 없어 반영하지 못합니다. 실전 성적은 `/live`의 예측 성적표에 매일 쌓입니다.

## 데이터 출처와 처리

| 출처 | API | 이용 조건 |
|---|---|---|
| 한국자산관리공사 온비드 | 차세대 온비드 물건 입찰결과목록, 차량 물건목록 | 공공데이터포털, 이용허락범위 제한 없음 |
| 한국교통안전공단 | 자동차 종합정보 성능점검정보 | 공공데이터포털, 이용허락범위 제한 없음 |

원본에서 발견해 처리한 것:
- 주행거리 수십억 km, 배기량 24,979cc 같은 오기 → 범위 밖이면 비움
- 같은 차의 표기 흔들림(포터Ⅱ/포터2/PORTERⅡ, 소나타/쏘나타) → 모델 계열로 묶음, 전기·하이브리드·리무진은 따로
- 제조사 칸이 절반가량 비어 있음 → 물건명에서 보충(낙찰 건 92% 채움)
- 성능점검 통계 2023-07(15,926,036건), 2025-05(4,513건) 이상값 → DB엔 원본 그대로, 차트에서만 비우고 화면에 표시

## 로컬 실행

```bash
cp .env.example .env            # DATA_GO_KR_KEY(공공데이터포털 인증키)와 MySQL 비밀번호 입력
docker compose up -d            # MySQL 8.4 (127.0.0.1:3307), db/schema.sql 자동 적용
npm install
npm run ingest                  # 2018-01부터 전체 수집(API 약 220회)
npm run ingest:stats
npm run snapshot
npm run evaluate                # 홀드아웃 검증 → data/metrics.json
npm run export
npx next dev                    # http://localhost:3000/used-car-compare/
npx next build && scripts/deploy.sh   # 정적 빌드 후 GitHub Pages(gh-pages 브랜치) 배포
```

매일 자동 실행은 `scripts/com.nopgae.used-car-compare.plist` 주석의 등록 명령을 참고하세요.
